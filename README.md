# ⚗️ ChemCrafter: The Interactive Chemistry Lab & Game
### مختبر الكيمياء التفاعلي واللعبة التعليمية الإبداعية

![ChemCrafter Banner](https://images.unsplash.com/photo-1532094349884-543bc11b234d?auto=format&fit=crop&w=1200&q=80)

> **ChemCrafter** هي منصة ولعبة تعليمية تفاعلية ثنائية اللغة (عربي / إنجليزي) تهدف إلى تبسيط وتجسيد مفاهيم الكيمياء الحديثة من خلال اللعب التجريبي والمحاكاة الفيزيائية الحية، ومربوطة بقاعدة بيانات سحابية لحظية (**Supabase**) لتسجيل المتصدرين ومشاركة ملاحظات المختبر.

---

## 🌟 المميزات الرئيسية (Core Features)

### 1. مختبر التفاعلات الكيميائية الحر (Reaction Sandbox)
- رف عناصر غني مستوحى من الجدول الدوري الحديث مع تصنيفات لونية (لا فلزات، فلزات قلوية، قلوية ترابية، فلزات انتقالية، هالوجينات، غازات نبيلة).
- إمكانية إضافة العناصر بالسحب والإفلات (Drag & Drop) أو بالنقر المباشر إلى دورق التفاعل الزجاجي.
- نظام محاكاة فيزيائية عبر Canvas للجسيمات واللهب والدخان والفقاعات والتأثيرات اللونية.
- مؤثرات طرد وامتصاص الحرارة ($\Delta H$) ومعادلات متزنة كيميائياً لكل ناتج.

### 2. طور المهمات والقصص التعليمية (Story Quests)
- 10 مستويات متدرجة تحاكي سيناريوهات واقعية:
  * إنقاذ طاقم الفضاء بتخليق الماء ($2\text{H}_2 + \text{O}_2 \rightarrow 2\text{H}_2\text{O}$).
  * ترويض العناصر الخطرة لإنتاج ملح الطعام ($2\text{Na} + \text{Cl}_2 \rightarrow 2\text{NaCl}$).
  * إطفاء الحرائق واحتجاز الكربون ($\text{CO}_2$).
  * تخليق سماد هابر-بوش لإطعام البشرية ($\text{NH}_3$).
  * شعلة المغنيسيوم المبهرة، وحمض المعدة الخارق، وتنفس الغواصات، وحجر الأهرامات.

### 3. ميزان المعادلات الكيميائية (Equation Balancer)
- محاكي تفاعلي لوزن المعادلات الكيميائية مع عدادات فورية للذرات في طرفي المتفاعلات والنواتج تحقيقاً لـ **قانون حفظ الكتلة** (Lavoisier's Law).

### 4. باني الذرات ونموذج بوهر (Bohr Atom Simulator)
- تحكم حي بعدد البروتونات ($p^+$)، والنيوترونات ($n^0$)، والإلكترونات ($e^-$).
- استعراض مستويات الطاقة المدارية (K, L, M, N).
- فحص استقرار النواة والنظائر المشعة والتأين والشحنة الكهربائية للذرة.

### 5. مؤثرات صوتية حية (Web Audio API)
- محرك صوتي مدمج يولد أصوات الغليان، وفرقعة الغاز، والشرارات الكهربائية، واشتعال النيران برمجياً بدون أي ملفات خارجية معرضة للتلف.

### 6. الربط السحابي مع Supabase
- حفظ النقاط والمستويات المكتملة في جدول `chemistry_leaderboard`.
- لوحة شرف عالمية للمنافسة بين الطلاب والمهتمين.
- حائط تجارب المجتمع `chemistry_community_notes` لمشاركة الأسرار والتجارب الكيميائية والإعجاب بها.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** Vanilla JavaScript (ES6 Modules), HTML5 Canvas, Tailwind CSS.
- **Database & Backend:** Supabase (PostgreSQL, Row Level Security, REST API).
- **Audio Engine:** Web Audio API (Synthesized oscillators and noise filters).
- **Deployment & CI/CD:** Netlify + GitHub.

## 🚀 تشغيل المشروع محلياً (Local Development)

يمكنك تشغيل المشروع بسهولة عبر أي خادم ويب ثابت (Static Server):

```bash
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node.js
npx serve .
```
ثم افتح المتصفح على: `http://localhost:8080`
